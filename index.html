Conectar con tus datos

  1. Tus gastos viven en datos.json dentro de un repositorio privado de tu GitHub.
  2. Pega un token fine-grained con acceso solo a ese repo y permiso Contents: Read and write.
  3. El token se guarda solo en este navegador. Hazlo una vez en cada dispositivo.
